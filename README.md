# 📊 Imersão Dados com Python - Alura

Este projeto foi desenvolvido durante a **Imersão de Dados com Python da Alura**, com o objetivo de aprender e aplicar conceitos de análise de dados utilizando Python.

## 📝 Sobre o projeto:

Neste repositório estão os notebooks e exercícios desenvolvidos ao longo da imersão, explorando dados reais e aplicando técnicas de análise exploratória de dados.

Durante as aulas foram trabalhados conceitos como:

- Importação e manipulação de dados
- Limpeza e tratamento de dados
- Visualização de dados
- Análise exploratória
- Criação de gráficos

O projeto demonstra na prática o processo inicial de análise de dados, contendo minhas anotações individuais em cima do material oferecido.
Foi uma experiência muito enriquecedora, e minha meta é retornar a esse repositório e fazer melhorias no meu projeto final, que foi um dashboard interativo usando o Streamlit.

---

## 🛠 Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
